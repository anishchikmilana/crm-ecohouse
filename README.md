# Проектирование CRM-системы для аренды экодомов
Студент: Анищик Милана Сергеевна, УИР-232
Курсовая работа

Проект: проектирование специализированной CRM-система для владельцев экодомов

Практическая часть: интерактивная симуляция бизнес-логики проекта
(защита от двойного бронирования, статусы брони, оплата через ЕРИП,
журнал учёта гостей, автозадачи, роли). Подготовлена с помощью
ИИ-ассистента на основе спроектированной логики.

## Как запустить
Установка не требуется. Откройте crm_simulation (1).html в браузере.
Вкладка «Проверки логики» запускает 7 сценариев.
